Comment lire les meubles “LOCKED” du jeu

Le problème de l'interface est qu'un meuble verrouillé peut afficher seulement une condition du type “8/10 Jobs” sans toujours afficher clairement quel meuble se cache derrière. Le tracker ci-dessus sert justement à faire le lien : tu entres tes compteurs et la page te donne la shortlist des prochains déblocages.

Important : les conditions Treadmill, Powerlifting Bench, Hackerman's Table, Military Receiver, Repair Workbench, Voucher Machine, Refund Chest, Requests Beacon, Mystery Box, Exchange Box, Trash Bin et Lucky Spin sont documentées par des guides/retours récents. Quand une condition reste incertaine — notamment Bookstand sur certaines builds — le wiki l'indique au lieu d'inventer.

Route de déblocage conseillée

  1. 30 objets volés : débloque le Treadmill naturellement.
  2. 3 Item Requests : vise Hackerman's Table, très rentable sur l'électronique.
  3. 10 Jobs : Powerlifting Bench, probablement le meilleur déblocage early/mid.
  4. 5000 C gagnés : Repair Workbench pour arrêter de jeter de l'argent dans les outils abîmés.
  5. 1 victoire : Voucher Machine + Military Receiver deviennent disponibles.
  6. 5 VIP : Requests Beacon, énorme pour finir les requests.
  7. 10 puis 20 Requests : Mystery Box puis Exchange Box.
  8. Extension 15000 C : King-size Bed, AC, Gold Stack et accès aux meubles de fin de progression.
