# Crime Simulator Wiki FR

Wiki communautaire français non officiel pour **Crime Simulator**.

Objectif : centraliser les mécaniques, stratégies, secrets, routes, équipements, compétences, Golden Cards, véhicules, heists, chimie et progression 100 % dans un site simple à consulter.

## Site

La page du wiki est dans `index.html` et est conçue pour être publiée avec **GitHub Pages**.

## Contenu actuel

- plan de progression et économie ;
- 25 compétences ;
- 24 Golden Cards ;
- Abilities et vouchers ;
- outils et upgrades de planque ;
- zones Rural, Lakeside, Texas, Rural Arizona et Ashen Creek ;
- vol de voitures ;
- recettes de chimie à 100 % ;
- heists ;
- techniques avancées et secrets ;
- objectif 100 % / succès ;
- recherche et checklists sauvegardées localement dans le navigateur.

## Contribuer

Les corrections et découvertes sont les bienvenues. Voir [`CONTRIBUTING.md`](CONTRIBUTING.md).

Pour éviter de propager de fausses informations, les données communautaires doivent idéalement être accompagnées d'une source, d'un screenshot, d'une vidéo ou d'une méthode de reproduction en jeu.

## Sources

Le wiki s'appuie en priorité sur :

- Steam Store et annonces officielles ;
- succès Steam ;
- guides Steam Community récents ;
- découvertes communautaires recoupées.

Les prix, probabilités, spawns et certains détails peuvent évoluer avec les mises à jour du jeu.
