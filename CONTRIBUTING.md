# Contribuer au Crime Simulator Wiki FR

Merci de participer au wiki.

## Ce qu'on accepte

- correction d'une information fausse ou périmée ;
- nouveau secret ou raccourci ;
- emplacement VIP / Golden Card ;
- stratégie de job ou de heist ;
- valeur, prix ou condition modifiée par un patch ;
- amélioration du site ;
- capture ou preuve d'une mécanique en jeu.

## Comment proposer une modification

1. Crée une branche depuis `main`.
2. Modifie `index.html`.
3. Explique clairement ce qui change.
4. Ouvre une Pull Request vers `main`.

Pour une simple information ou un doute, ouvre plutôt une **Issue**.

## Preuves recommandées

Pour les informations susceptibles de varier avec les versions, indique si possible :

- version du jeu ;
- zone / maison / mission ;
- difficulté ;
- solo ou coop ;
- screenshot, vidéo ou lien Steam ;
- étapes permettant de reproduire le résultat.

## Règles éditoriales

- distinguer une mécanique confirmée d'une observation communautaire ;
- utiliser `≈` lorsqu'une valeur n'est pas garantie ;
- ne pas présenter du RNG comme un spawn garanti ;
- ne pas supprimer une information utile sans expliquer pourquoi ;
- garder le wiki lisible en français.

## Format des commits

Exemples :

- `fix: correct Golden Card effect`
- `docs: add VIP location for 211`
- `feat: add Ashen Creek route`
- `style: improve mobile table layout`

## Validation

Les Pull Requests sont relues avant fusion afin de maintenir une base fiable.
